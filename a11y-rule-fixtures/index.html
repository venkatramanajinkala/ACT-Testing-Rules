Accessibility Rule Fixtures

Regression-test fixtures for 15 ACT accessibility rules.

  • accessibility-rules-fail.html — intentional failing test cases
  • accessibility-rules-pass.html — corrected passing equivalents
  • quarterly-service-report.html — HTML alternative used by the R100 PASS case
  • scrollable-region-focus-demo.html — interactive R84 demo with a live broken/fixed toggle and focus status readout
  • sticky-header-focus-demo.html — interactive R119 demo with a live broken/fixed toggle and focus status readout
  • README.md — full documentation, rule list, and verification steps

See README.md for which rules are automatic-scan vs. manual/behavioral review.
